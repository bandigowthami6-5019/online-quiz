Online Quiz Application
📌 About the Project

The Online Quiz Application is a simple and interactive web-based quiz developed using HTML, CSS, and JavaScript.

The application presents multiple-choice questions to users, allows them to select answers, automatically checks the answers, calculates the score, and displays the final result.

✨ Features

Multiple-choice questions

Interactive answer selection

Automatic answer checking

Score calculation

Result display

Restart quiz option

Responsive design

Simple and user-friendly interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript

🚀 How to Run

Download or clone the repository.

Open the project folder.

Double-click index.html.

The quiz will open in your web browser.

Select an answer and click the Next button.

Complete the quiz to see your score.

No server or additional software is required.
